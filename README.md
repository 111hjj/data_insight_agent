# 数据洞察 Agent 📊

> 一个基于自然语言的数据分析与可视化工具，让非技术人员也能轻松分析数据

## ✨ 功能特点

- **自然语言查询**：用中文提问，自动生成分析代码
- **多文件支持**：同时上传多个CSV/Excel文件进行对比分析
- **智能图表**：自动选择合适的图表类型（柱状图、折线图、饼图等）
- **深度分析模式**：支持多轮对话，保持上下文理解
- **异常检测**：自动识别数据中的异常值并给出建议
- **报告生成**：一键生成完整的数据分析报告

## 🛠️ 技术栈

### 后端
- **框架**: FastAPI (Python)
- **数据处理**: Pandas, NumPy
- **可视化**: Matplotlib, Seaborn
- **AI模型**: OpenAI API / Ollama (本地部署)

### 前端
- **UI框架**: Tailwind CSS (CDN)
- **交互**: 原生 JavaScript (Vanilla JS)
- **特性**: 响应式设计、流式输出、Markdown渲染

## 🔧 核心功能说明

### 快速分析 vs 深度分析

| 特性 | 快速分析 | 深度分析 |
|------|---------|---------|
| 适用场景 | 简单的一次性查询 | 复杂的多轮对话 |
| 上下文 | 无 | 支持 |
| 多文件 | 基础支持 | 完整支持 |
| 输出方式 | 同步返回 | SSE流式输出 |

### 支持的分析类型

1. **描述统计**：均值、中位数、标准差等
2. **数据预览**：查看前几行、列信息
3. **可视化图表**：
   - 柱状图（分类对比）
   - 折线图（趋势变化）
   - 饼图（占比分布）
   - 直方图（数值分布）
4. **高级分析**：
   - 异常值检测
   - 趋势预测
   - 相关性分析
   - 完整报告生成

## 📝 开发笔记

### 设计思路
这个项目的灵感来自于我想让数据分析变得更简单。传统的数据分析需要学习SQL、Python等编程语言，门槛很高。通过结合大语言模型的代码生成能力，用户只需要用自然语言描述需求，系统就能自动完成分析。

### 技术亮点
1. **安全的代码执行**：通过白名单机制和超时限制，防止恶意代码执行
2. **意图识别**：基于正则表达式的规则匹配 + LLM降级方案
3. **流式输出**：使用SSE技术，提升用户体验
4. **上下文管理**：简单的内存存储实现对话历史
